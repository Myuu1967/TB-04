# TB-04 ver2 IC 一覧

TB-04 ver2 の基板3枚の IC 68個（PCB 上の数。4060 は抜いているので実装は67個）について、型式ごとに「どんな IC か」と「どこでどう使っているか」をまとめたものです。
接続は各基板の PCB データ（`hardware/基板分割_0827/`）から取り出しています。ブロックとの対応は [README のブロック図](README.md#ブロック図) を参照してください。

- ロジック IC は 74HC シリーズです（例外は 74AHC04 と 74HCT10 の1個ずつ）。回路図のシンボルが 74LS になっているものは、KiCAD に HC のシンボルがないための代用で、実装はすべて HC です。
- 信号名の `~` は負論理（L で有効）を表します。論理式の `&` は AND、`|` は OR、`!` は否定です。

外付けのクロック供給ユニット [clock4096](../peripherals/clock4096/) には、ほかに 74HC04（RC 発振）と 4040（12段分周）を使っています。

## 28C256

32K×8bit の並列 EEPROM です。ver2 では「書き換えられる真理値表」として使い、命令メモリのほか、ALU とデコーダもこの ROM で作っています。アドレスに入力をつなぎ、データ出力をそのまま結果として使います。

| 参照 | 基板 | 役割 | 接続 |
|---|---|---|---|
| U604 | 制御板 | 命令 ROM（ZIF ソケット） | A0-7 ← アドレスバス、A8-11 ← バンク切替スイッチ `SW601`、D0-7 → MD0-7、`~OE` ← `~OE_ROM` |
| U603 | 演算板 | ALU | A0-3 ← `alu_a`、A4-7 ← `alu_b`、A8-11 ← `alu_code`、A12 ← `carry_in` → D0-3 = `DI0-3`（演算結果）、D4 = `carry_out`、D5 = `zero_flag` |
| U704 | 演算板 | デコーダ ROM A（ALU 用） | A0-3 ← `OPR0-3`、A4-7 ← `OPC0-3`、A8 ← `carry_in`、A9 ← `zero_prev` → U702 |
| U703 | 制御板 | デコーダ ROM B | 入力は U704 と同じ → U701 |
| U706 | 制御板 | デコーダ ROM C | 入力は U704 と同じ → U705 |

デコーダ ROM にフラグ（C・Z）も入れているので、条件分岐の成立・不成立も ROM の中で決まります。

## 6116

2K×8bit の SRAM です。256番地のうち 0xC0〜0xF7 の範囲だけを使います。

| 参照 | 基板 | 役割 | 接続 |
|---|---|---|---|
| U1101 | 制御板 | RAM（0xC0〜0xEF）とスタック（0xF0〜0xF7） | A0-7 ← アドレスバス、D0-7 ↔ MD0-7、`~CS` ← `~CS_RAM`、`~OE` ← `WR`、`~WE` ← `~WE_RAM` |

## 74HC161

4bit の同期カウンタです。クロック（`CP`）の立上りで、`~PE` が L ならデータ入力を取り込み、そうでなく `CEP`・`CET` が H なら +1 します。`~MR` で 0 にクリアされます。ver2 では「取り込むだけ」のレジスタ、「数えて取り込む」PC、「数えるだけ」の位相カウンタの3通りに使っています。

| 参照 | 基板 | 役割 | 接続 |
|---|---|---|---|
| IC201〜IC204 | 演算板 | レジスタ R0〜R3 | D ← `DI0-3`、`~PE` ← `~Reg_WE0`〜`3`、CP ← `CLK_CPU`、Q → 読出し MUX と LED |
| IC301〜IC304 | 演算板 | レジスタ R4〜R7 | 同上（`~Reg_WE4`〜`7`） |
| IC402 | 制御板 | PC 下位 4bit | D ← `PC0-3`、Q → `PC_Q0-3`、`CEP`・`CET` ← `PC_CNT_EN`、`~PE` ← `~PC_PE` |
| IC401 | 制御板 | PC 上位 4bit | D ← `PC4-7`、Q → `PC_Q4-7`、`CET` ← IC402 の桁上げ |
| IC601 | 制御板 | 位相カウンタ | Q0・Q1 → U607（0→1→2→3 を繰り返す） |

## 74HC193

4bit のアップダウンカウンタです。`UP`・`DOWN` の2本のクロック入力を持ち、`~LOAD` でデータ入力の値をプリセットします。

| 参照 | 基板 | 役割 | 接続 |
|---|---|---|---|
| U1201 | 制御板 | SP（3bit を使用） | `UP` ← `CU`、`DOWN` ← `CD`、`~LOAD` ← `~RST`（リセットで 7）、Q0-2 → `SP0-2` |

## 74HC273

8bit の D フリップフロップです。クロックの立上りで 8bit をまとめて取り込み、`~MR` でクリアされます。

| 参照 | 基板 | 役割 | 接続 |
|---|---|---|---|
| U602 | 制御板 | 命令レジスタ byte1 | D ← MD0-7、CP ← `FCH2` → Q = `OPR0-3`（下位）・`OPC0-3`（上位） |
| U606 | 制御板 | 命令レジスタ byte2 | D ← MD0-7、CP ← `DCR` → Q = `OPR4-7`（下位）・`OPR8-11`（上位） |
| U701 | 制御板 | 制御ラッチ（U703 の出力） | CP ← `DCR` → `SEL_Y`・`SEL_M0`・`SEL_M1`・`SEL_PC`・`RegAddrSrc`・`PC_LOAD`・`SP_CU`・`SP_CD` |
| U705 | 制御板 | 制御ラッチ（U706 の出力） | CP ← `DCR` → `~WE`・`C_WE`・`Z_WE`・`WR`・`~SEL_Y` |
| U702 | 演算板 | 制御ラッチ（U704 の出力） | CP ← `DCR` → `alu_code0-3`・`SEL_A`・`SEL_B0`・`SEL_B1`・`SEL_IMM` |
| U601 | 制御板 | Y ラッチ | D ← `DI0-3`、CP ← `EXE` → `YD0-3`（4bit を使用） |

デコーダ ROM の出力を `DCR` でラッチしているので、EXE の間は制御信号が変わりません。

## 74HC377

8bit の D フリップフロップで、`~E` が L のときだけクロックで取り込みます。クロックを加工せずに「どのポートに書くか」を選べるので、OUT ポートに使っています。

| 参照 | 基板 | 役割 | 接続 |
|---|---|---|---|
| U905 | IF 板 | OUT ポート 0 | D ← MD0-3、`~E` ← `OUTPUT0`、CP ← `~CLK_CPU`、Q → LED と外部端子（4bit を使用） |
| U901 | IF 板 | OUT ポート 1 | 同上（`~E` ← `OUTPUT1`） |
| U902 | IF 板 | OUT ポート 2 | 同上（`~E` ← `OUTPUT2`） |
| U903 | IF 板 | OUT ポート 3 | 同上（`~E` ← `OUTPUT3`） |

## 74HC74

D フリップフロップ2個入りです。

| 参照 | 基板 | 役割 | 接続 |
|---|---|---|---|
| U605 | 演算板 | フラグ C と Z | C: D ← `carry_out`、CK ← `CLK_C` → `carry_in`／Z: D ← `zero_flag`、CK ← `CLK_Z` → `zero_prev` |

フラグを書き換えない命令ではクロック（`CLK_C`・`CLK_Z`）を止めて値を保ちます（`CLK_C = FCH1 & C_WE`）。

## 74HC244

8bit の 3ステートバッファです（4bit ×2組、組ごとに `~OE`）。バスに「つなぐ・切り離す」を切り替える部品で、アドレスバスとメモリデータバスに値を出す口はすべてこの IC です。

| 参照 | 基板 | 役割 | 接続 |
|---|---|---|---|
| U1001〜U1004 | IF 板 | IN ポート 0〜3 | IN 4bit → MD0-3、MD4-7 は 0、`~OE` ← `INPUT0`〜`3` |
| U1402 | 制御板 | アドレス源: mAddr | `OPR4-11` → A0-7、`~OE` ← `~OE_mAddr` |
| U1403 | 制御板 | アドレス源: PC | `PC_Q0-7` → A0-7、`~OE` ← `EXE`（EXE 以外の相で出す） |
| U1404 | 制御板 | アドレス源: SP | `SP0-2` → A0-2、上位は固定で 0xF0 + SP |
| U1405 | 制御板 | アドレス源: I/O | ポート番号 → A0-1、`SEL_M0` → A2、上位は固定で 0xF8〜0xFF、`~OE` ← `~OE_ioAddr` |
| U1102 | 制御板 | Y ドライバ: 演算結果 | `YD0-3` → MD0-3、MD4-7 は 0、`~OE` ← `~YEN_Y` |
| U1103 | 制御板 | Y ドライバ: 戻り番地 | `PC_Q0-7` → MD0-7（CALL）、`~OE` ← `~YEN_PC` |

I/O 中にアドレスを 0xF8〜0xFF へ逃がす（U1405）のは、IN・OUT のあいだ ROM と RAM を選ばないようにするためです。

## 74HC253

4入力1出力のマルチプレクサ2個入りで、出力が 3ステートです。選択信号 S0・S1 は2個で共通、`~OE` は個別です。3ステートなので、R0〜R3 用と R4〜R7 用の出力を同じ線につなげます。

| 参照 | 基板 | 役割 | 接続 |
|---|---|---|---|
| U201・U202 | 演算板 | a ポート読出し（R0〜R3） | S ← `sel_a0-1`、`~OE` ← `sel_a2` → `DOa0-3` |
| U301・U302 | 演算板 | a ポート読出し（R4〜R7） | S ← `sel_a0-1`、`~OE` ← `~Ena_RS01` → `DOa0-3` |
| U203・U204 | 演算板 | b ポート読出し（R0〜R3） | S ← `OPR4-5`、`~OE` ← `OPR6` → `DOb0-3` |
| U303・U304 | 演算板 | b ポート読出し（R4〜R7） | S ← `OPR4-5`、`~OE` ← `~Enb_RS01` → `DOb0-3` |
| U402・U405 | 演算板 | ALU a 入力の選択 | S ← `SEL_IMM`・`SEL_A`：`DOa`／`OPR0-3`（byte1 の即値）／`OPR4-7`（byte2 の即値） → `alu_a0-3` |
| U403・U406 | 演算板 | ALU b 入力の選択 | S ← `SEL_B0`・`SEL_B1`：`DOb`／MD0-3（LD・POP・IN）／`OPR4-7`（即値）／0 → `alu_b0-3` |

a ポート（Ri）と b ポート（Rj）を別々の IC で同時に読み出すので、`ADD Ri,Rj` のような2オペランドの演算が1命令でできます。

## 74HC157

2入力1出力のマルチプレクサ4個入りです（選択信号 S は4個で共通）。

| 参照 | 基板 | 役割 | 接続 |
|---|---|---|---|
| U401 | 制御板 | 分岐先の選択（下位） | S ← `SEL_PC`：`OPR4-7`（命令の番地）／MD0-3（RET の戻り番地） → `PC0-3` |
| U404 | 制御板 | 分岐先の選択（上位） | 同上：`OPR8-11`／MD4-7 → `PC4-7` |
| U101 | 制御板 | Ri アドレスの選択 | S ← `RegAddrSrc`：`OPR8-10`（通常）／`OPR0-2`（LD・ST） → `sel_a0-2`（3個を使用） |
| U1406 | 制御板 | ポート番号の選択 | S ← `SEL_IMM`：`OPR4-5`／`OPR8-9` → `port0-1`（2個を使用） |

## 74HC138

3→8 のデコーダで、選ばれた1本だけが L になります。イネーブルが3本（負論理2本・正論理1本）あり、相信号で囲うのに使っています。

| 参照 | 基板 | 役割 | 接続 |
|---|---|---|---|
| U102 | 演算板 | レジスタの書込先の選択 | 入力 ← `sel_a0-2`、イネーブル ← `~WE`・`EXE` → `~Reg_WE0`〜`7`（各レジスタの `~PE`） |
| U1401 | 制御板 | アドレス源の選択 | 入力 ← `SEL_M0-1`、イネーブル ← `EXE` → `~OE_mAddr`・`~OE_spAddr`・`~OE_iAddr`・`~OE_oAddr`（4本を使用） |

## 74HC139

2→4 のデコーダ2個入りです（出力は負論理）。

| 参照 | 基板 | 役割 | 接続 |
|---|---|---|---|
| U1407 | 制御板 | IN / OUT ポートの選択 | 入力 ← `port0-1`／IN 側: イネーブル ← `~OE_iAddr` → `INPUT0`〜`3`／OUT 側: イネーブル ← `~OE_oAddr` → `OUTPUT0`〜`3` |

`INPUT0-3`・`OUTPUT0-3` はデータではなく、どのポートを使うかを選ぶストローブです。

## 74HC238

3→8 のデコーダで、74HC138 と違い選ばれた1本が H になります。

| 参照 | 基板 | 役割 | 接続 |
|---|---|---|---|
| U607 | 制御板 | 相信号の生成 | 入力 ← IC601 の Q0・Q1 → `FCH1`・`FCH2`・`DCR`・`EXE`（4本を使用・常にどれか1本だけ H） |

## 74HC08

2入力 AND が4個入っています。

| 参照 | 基板 | 役割 | 論理 |
|---|---|---|---|
| U1301 | 制御板 | アドレス領域の判定 | `P2 = A7 & A6`（0xC0 以上）、`P4 = P2 & A5 & A4`（0xF0 以上）、`P5 = P4 & A3`（0xF8 以上＝I/O） |
| U1503 | 制御板 | フラグと SP の制御 | `CLK_C = FCH1 & C_WE`、`CLK_Z = FCH1 & Z_WE`、`CD_pre = SP_CD & SP_NE0`、`CU_pre = SP_CU & SP_NE7` |

## 74HC00

2入力 NAND が4個入っています。制御信号を相信号（`EXE`・`DCR`）で囲い、その相の間だけ有効にするのに使っています。

| 参照 | 基板 | 役割 | 論理 |
|---|---|---|---|
| U1504 | 制御板 | SP・PC・ROM の制御 | `CD = !(CD_pre & EXE)`、`CU_raw = !(CU_pre & DCR)`、`~PC_PE = !(PC_LOAD & EXE)`、`~OE_ROM = !(ROM_SEL & ~WR_EXE)` |
| U1505 | 制御板 | MD への書き出しと I/O アドレス | `~YEN_Y = !(WR_EXE & ~SEL_Y)`、`~YEN_PC = !(WR_EXE & SEL_Y)`、`~WR_EXE = !(WR & EXE)`、`~OE_ioAddr = !(SEL_M1 & EXE)` |

## 74HCT10

3入力 NAND が3個入っています。回路図と PCB の値は 74HC10 ですが、74HC10 が手に入らなかったため 74HCT10 を使っています。
HCT は入力のしきい値が TTL 並み（約1.4V）で、出力は HC と同じ CMOS のフルスイングです。74LS10 で代用すると出力の H が低くなり、プルアップ抵抗を2本足す改造が要りましたが、HCT なら差し替えるだけで済みます（入力は HC の出力が 5V で駆動するので、しきい値が低くても問題ありません）。

| 参照 | 基板 | 役割 | 論理 |
|---|---|---|---|
| U1509 | 制御板 | RAM の選択と書込パルス・SP の上限判定 | `~CS_RAM = !(P2 & ~P5 & EXE)`（0xC0〜0xF7 を EXE の間だけ選ぶ）、`~WE_RAM = !(CS_RAM & WR & CLK_CPU)`、`SP_NE7 = !(SP0 & SP1 & SP2)` |

`~WE_RAM` を作るゲートのクロック入力（9番ピン）は、実機では 1kΩ と 220pF で遅らせています。CALL で戻り番地を書き込むとき、EXE の終わりに短い書込パルスが出てスタックを上書きしていたための対策です（回路図には未反映）。

## 74HC32

2入力 OR が4個入っています。

| 参照 | 基板 | 役割 | 論理 |
|---|---|---|---|
| U1506 | 制御板 | SP・PC の制御 | `SP_NE0 = SP0 \| SP1 \| SP2`（2個を使用・SP が 0 でない）、`PC_CNT_EN = FCH1 \| FCH2`、`CU = CU_raw \| CLK_CPU` |

`SP_NE0`・`SP_NE7` は、スタックが空・満杯のときに SP を動かさないためのガードです。

## 74AHC04

インバータが6個入っています。

| 参照 | 基板 | 役割 | 論理 |
|---|---|---|---|
| U1501 | 制御板 | 信号の反転 | `ROM_SEL = !P2`、`~P5 = !P5`、`WR_EXE = !~WR_EXE`、`CS_RAM = !~CS_RAM`、`~Ena_RS01 = !sel_a2`、`~Enb_RS01 = !OPR6` |

## 74HC14

シュミットトリガ入力のインバータが6個入っています。入力のしきい値にヒステリシスがあるので、ゆっくり変わる信号やチャタリングのある信号を、きれいなデジタル信号に整えられます。

| 参照 | 基板 | 役割 | 接続 |
|---|---|---|---|
| U501 | IF 板 | リセットとクロックの整形 | リセットボタン `SW503` → RC → `RST` → `~RST`／手動クロックのボタン `SW501` → RC でチャタリング除去 → 速度切替 `SW502` → `CLK_CPU` → `~CLK_CPU` |

## 4060

発振回路付きの 14段分周カウンタです。32.768kHz の水晶で発振させて分周し、クロックを作る予定でしたが、周波数が安定しなかったため使っていません。代わりに外付けの [clock4096](../peripherals/clock4096/)（74HC04 の RC 発振＋4040 の分周）からクロックを入れています。

| 参照 | 基板 | 役割 |
|---|---|---|
| U502 | IF 板 | 抜いている（ソケットのみ）。外付けクロックと出力が競合しないようにするため |

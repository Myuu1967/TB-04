# clock4096 — TB-04 用クロック供給ユニット

RC 発振で約 4096Hz を作り、4040 で分周して、ロータリースイッチで 9 段階の周波数を選べるクロック供給ユニットです。
TB-04 ver2 では、IF 板の水晶発振（32.768kHz＋74HC4060）の周波数が安定しなかったため、その代わりにこのユニットからクロックを入れています。

ユニバーサル基板で製作しました（PCB は起こしていません）。

回路図: [`clock4096.pdf`](clock4096.pdf)（KiCAD 10.0 の `clock4096.kicad_sch` から出力）

## 構成

| 項目 | 内容 |
|---|---|
| 発振 | 74HC04 2段の RC 発振（`R4` 100kΩ・`R2` 1kΩ 可変＋`R3` 150Ω・`C4` 0.1µF）。周波数は `R2` で合わせる |
| 分周 | 4040（12段バイナリカウンタ） |
| 周波数の選択 | ロータリースイッチ `SW2`：4096（原発振）・2048・1024・512Hz（Q0〜Q2）／16・8・4・2・1Hz（Q7〜Q11） |
| 出力の切替 | スライドスイッチ `SW1`：Manual（`J2` から入れた手動クロック）／Auto（`SW2` で選んだクロック）→ `J3` Clock Out |
| 電源 | 5V（`J1`） |

## 使い方の注意

- **4096Hz（原発振）は使っていません。** 4040 を通さない信号のためかヒゲが出て、数えると 5000Hz 以上になるなど不安定でした。配線は残してあります。
- **4040 の Reset は、回路図では GND ですが、実機では TB-04 の IF 板からリセット信号を配線しています。**

## TB-04 ver2 へのつなぎ方

IF 板にあるもとのクロック回路のうち、手動（Manual）動作用の信号をこのユニットの `J2` へ回し、`SW1` でこのユニットのクロックと切り替えます。`J3` の出力は IF 板の `CLK_CPU` の信号線につないでいます。
